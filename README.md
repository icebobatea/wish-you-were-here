# Wish You Were Here — A Century of Victorian Postcards

FIT3179 Data Visualisation 2 (Monash University, 2026). Live page: https://icebobatea.github.io/wish-you-were-here/

- `index.html`, `styles.css` — the single scrollable page
- `js/*.vg.json` — one Vega-Lite spec per chart (12 charts)
- `data/` — chart data
  - `mv_postcards_raw.csv` — export from the Museums Victoria Collections API
  - `ref/vic_suburb_coords.csv`, `victoria.geojson` — reference geography for the Victoria maps
  - everything else is generated by the scripts below
- `scripts/prepare.py` — builds the postcard datasets: `python scripts/prepare.py`
- `scripts/prepare_abs.py` — builds the birthplace datasets from the ABS Country of Birth data cube
  (3105.0.65.001, 2014): `python scripts/prepare_abs.py path/to/3105065001ds0008_2014.xls`
